# Python & Exploratory Data Analysis Exercises

This folder contains exercises completed during **Week 1 of the Winter School of Data Science (WiDS) 2025**.  
The objective of this phase was to build a strong foundation in **Python programming** and **exploratory data analysis (EDA)** through hands-on practice.

---

## Objectives
- Learn Python syntax and basic programming concepts
- Understand how to work with structured datasets
- Perform exploratory data analysis using standard Python libraries
- Develop good coding and data analysis habits

---

## Topics Covered
- Python basics and control flow
- Working with NumPy arrays
- Data manipulation using Pandas
- Handling missing and inconsistent data
- Descriptive statistics
- Data visualisation using Matplotlib

---

## Learning Outcomes
- Ability to load and inspect datasets
- Cleaning and preprocessing raw data
- Identifying patterns and anomalies using EDA
- Creating meaningful plots to summarise data
- Writing clean and readable Python code

These exercises laid the groundwork for all subsequent data analysis and machine learning tasks in the program.
