# Learning Projects Using Real-World Datasets

This folder contains small **data analysis projects** completed during **Week 2 of the Winter School of Data Science (WiDS) 2025**.  
The goal of this phase was to apply Python and EDA skills to complete **end-to-end analysis on real datasets**.

---

## Objectives
- Apply data analysis skills independently
- Work with unfamiliar datasets
- Practice data cleaning and feature selection
- Extract insights and communicate results

---

## Project Workflow
Each project typically involved:
1. Understanding the dataset and its context
2. Cleaning and preprocessing data
3. Exploratory data analysis and visualisation
4. Summarising insights and observations

---

## Skills Developed
- Handling real-world data imperfections
- Framing analytical questions
- Choosing appropriate visualisations
- Interpreting results in context

These projects helped bridge the gap between structured exercises and open-ended problem solving.
